# Docs viewer

The docs viewer is a local development tool. It shows the Markdown
documentation of a repository in a browser, as an Obsidian vault shows its
notes: a file tree, rendered notes, search, backlinks, an outline, and a
link graph. It also shows the changes in a file against git, and it shows
OpenAPI specs as API reference pages. The viewer only reads: it changes no
file.
